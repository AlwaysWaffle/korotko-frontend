# Коротко — сервис сокращения ссылок

Клиентское приложение на React, Vite и TypeScript для управления короткими ссылками и аналитикой. Все запросы к бэкенду собраны в `src/api/`.

## Установка и запуск

Требуется Node.js 18 или новее.

```bash
npm install
cp .env.example .env
npm run dev
```

Для production-сборки и локального просмотра:

```bash
npm run build
npm run preview
```

## Переменные окружения

Скопируйте `.env.example` в `.env` и при необходимости измените значения:

| Переменная | Значение по умолчанию | Описание |
| --- | --- | --- |
| `VITE_API_URL` | `http://localhost:8000` | Базовый адрес API; в мок-режиме используется как origin коротких ссылок. |
| `VITE_USE_MOCK` | `false` | Установите `true`, чтобы использовать локальные тестовые ответы вместо API. |

Чтобы включить мок-режим, задайте `VITE_USE_MOCK=true` в `.env`. Войти можно с любым корректным email и паролем длиной от 6 символов. Ссылки мок-режима хранятся в `localStorage`.

После изменения переменных окружения перезапустите Vite.

## Маршруты

- `/login`, `/register` — вход и регистрация.
- `/links` — создание ссылок, фильтрация, управление и пагинация.
- `/links/:id/stats` — статистика переходов и источники.

Публичный маршрут `/{code}` намеренно не реализован: редирект выполняет бэкенд.
